# Default images

The replaceable profile and project images are in `defaults/`:

- `profilepic.jpg` is used for the profile picture at the end of the home page.
- `bg.jpg` is used as the background on the About page opened from the menu.
- `my-first-portfolio.png` is used for Lawliet Portfolio.
- `apple+codes.png` is used for Apple Codes.

Replace a file and keep its name to update the picture. If you use a different filename, update the path in `src/constants/projects.js` (project images) or the matching About page component (profile/background image).
